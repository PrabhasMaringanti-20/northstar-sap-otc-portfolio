# Proposed responsibility matrix

Independent simulated portfolio · 2026-10-11 · AI-assisted draft; learner review pending.

A = accountable for the outcome; R = performs work; C = consulted; I = informed. One accountable role per activity. A/R combines responsibility for this small-company simulation, not every named employee. Credit request and release must remain separated.

| Activity | Sales | Warehouse | Finance | Customer Service | IT |
| --- | --- | --- | --- | --- | --- |
| Customer/order validation | A/R | I | C | C | I |
| Promise and partial agreement | A/R | C | I | C | I |
| Credit release | C | I | A/R | I | I |
| Dispatch and goods issue | C | A/R | C | I | I |
| Billing and corrections | I | C | A/R | C | I |
| Payment allocation | I | I | A/R | C | I |
| Customer exception communication | C | C | C | A/R | I |
| Role/report configuration | C | C | C | C | A/R |
