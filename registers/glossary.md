# Working glossary

| Term | Meaning |
|---|---|
| Order-to-Cash | Activities from receiving a customer order through collecting and matching payment |
| Requirement | Clear statement of a needed outcome or behaviour |
| Business rule | Policy or condition governing a business decision or action |
| Control | Check or restriction that prevents or detects an error |
| Exception | Situation requiring handling outside the normal flow |
| Root-cause hypothesis | Possible underlying explanation still requiring evidence |
| Acceptance criterion | Observable condition for judging whether a requirement is met |
| KPI | Key performance indicator: defined measure used to monitor performance |
| UAT | User acceptance testing: checking whether a solution meets business needs |
| Traceability | Links connecting problems, requirements, design and validation |
| ERP | Enterprise resource planning: software supporting connected business activities and records |
| BRD | Business requirements document: explanation of business needs, scope and requirements |
| AS-IS / TO-BE | Current process / proposed future process |
| Backlog | Prioritised collection of work or product needs |
| User story | Short statement of a user's need and its business value |
| Goods-issue posting | System record of an outbound stock movement; exact SAP effects require verification |
| Payment allocation | Matching received money to the correct invoice or account |
| Synthetic data | Artificial records generated for analysis or testing |
| Edition / release | Product offering and operating model / version of that offering |
| Fit-to-standard | Comparing business needs with standard system/process capabilities |

These are learning definitions, not a verified SAP capability register.

## Terms introduced in the full build

| Term | Meaning |
|---|---|
| Grain | What one data row represents |
| Primary / foreign key | Unique row identifier / reference to another table's row |
| Fan-out | Multiplication of parent rows when several child tables are joined |
| Business partner | Common identity and role-specific master information; see SAP-005 |
| ATP | Available to promise: date/quantity confirmation concept; see SAP-002 |
| PGI | Post goods issue; recording an outbound stock movement, not customer receipt |
| Receivable | Amount owed by a customer |
| Partial payment | Payment linked to an invoice while original invoice remains open; see SAP-006 |
| Residual item | Remaining balance item after clearing the original invoice; see SAP-006 |
| On-account payment | Payment recorded without matching a particular invoice |
| RACI | Responsible, Accountable, Consulted and Informed responsibilities |
| Segregation of duties | Separating conflicting actions, such as requesting and approving release |
| Capacity released | Staff time available for other work; not necessarily cash saved |
| Severity / priority | Impact of a defect / urgency of resolving it |
| Configuration / extension | Setting standard behaviour / adding capability beyond the chosen standard |
