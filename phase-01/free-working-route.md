# Selected route — no required paid software

> Supersession note — 11 October 2026: the user authorized building all phases. This Phase 1 draft is retained as the starting charter. Current status and decisions are in ../registers/progress.md and ../registers/decisions.md. Public Edition 2602 is now the research reference. Initial “not started” and evidence-pending statements below describe 8 October, not the current artifact set.

Decision: use documentation, synthetic data and reproducible analysis. SAP practice access is still unknown and is not required to complete the portfolio. Do not buy a subscription or start a payment-card trial for this project.

This route best fits a beginner building evidence of business analysis: the work can demonstrate clear requirements, process reasoning, controls, data analysis and test design without implying hands-on SAP implementation. Public Edition remains a provisional research reference, not a free SAP system or purchase recommendation.

## Tools and formats

- Read the complete Phase 1 pack in the standalone HTML file using a browser. It has no external fonts, scripts, accounts or network requests. Use the browser's Print / Save as PDF option if available.
- Edit Markdown sources using a plain-text editor. They are the authoritative versions used to generate the pack.
- Open DOCX and XLSX copies in the free LibreOffice Writer and Calc applications. Microsoft Office is not required. Layout may vary between applications; LibreOffice rendering has not been tested here.
- CSV copies of each workbook sheet provide simple, portable access. CSV does not retain workbook formatting.
- Later data work will use CSV, free Python tools and optionally SQLite. A spreadsheet-based dashboard can use LibreOffice Calc. Power BI and paid sharing services are not required.
- Use publicly accessible official SAP documentation and free SAP Learning material where available. Check access and edition before relying on a source. If a resource requires payment, find another official public source or label the claim unverified. Do not assume practice systems, certifications or all SAP training are free.
- Keep artifacts in the workspace and download local copies. GitHub publishing remains optional and requires a later user request; no paid hosting or domain is needed.

## Cost boundary

Required incremental software purchases for this planned route: £0. This is a project tooling decision, not a business-case saving. Existing device, internet and this chat/cloud service are outside that estimate; their pricing and availability are not controlled by this project. No guarantee of free ongoing cloud hosting is made. Downloaded source files can be used independently of this workspace.

## Alternatives and limitations

A paid SAP practice environment could add demonstrated system evidence but is not needed for the chosen route. A documentation-based portfolio cannot claim system configuration, integration execution or SAP UAT execution. All unrun SAP cases will remain Not executed. Data checks and walkthroughs will be labelled separately.

The full twelve-phase project is still planned, but only Phase 1 is built. Learning reviews remain part of the approach; requesting a free version does not supply answers or prove understanding.
